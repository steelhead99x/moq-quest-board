# Security

## Reporting a vulnerability

Please report security problems privately through GitHub's
[Report a vulnerability](https://github.com/steelhead99x/moq-quest-board/security/advisories/new)
form on this repository's Security tab. Do not open a public issue for them.

Include what you found, how to reproduce it and the impact you expect.
This is a small hobby project, so there is no bounty and no promised response time.

Quest Board is meant to run on your own machine. It binds to 127.0.0.1 by default and runs only `quest` and `gh`. Exposing it on a network is out of scope.

Bugs that are not security problems can go in a normal issue.
